# Changelog

## 0.3.0 — Baal benchmark (magic phase, part 1)
- New Djinn Arts engine: server-side timelines (charge, telegraph, release), shared damage/area helpers, budgeted effects.
- Baal's arts: Lightning Spear, Chain Lightning, Thunder Cage, **Bararaq Saiqa** (sky lightning stored in your sword,
  released as an enormous sky-lighting blast; needs a sword) and **Extreme Magic: Bararaq Inqerad-Saiqa** (sky magic
  circle, marked lightning storm, colossal spectral greatsword impact, crater; needs a sword, Djinn level 5, full energy).
  Signature ability: Lightning Dash.
- Costs Iron's Spells mana and scales with Iron's spell power / cooldown reduction when Iron's is installed
  (Djinn Energy otherwise). Claims are respected; crater size and block damage are configurable.
- Keys G / H / J, gold-framed Djinn HUD, sky flash, screen flash, camera shake, custom sounds with subtitles,
  custom damage type and death messages, 3D spectral greatsword, generated magic-circle texture and art icons.
- Network protocol 3.

## 0.2.0 — revamp
- Every item now has a detailed 3D model (Persian/Arabian style): shamshir-style scimitars, kilij sabers, khanjar daggers,
  pennant spears, crescent tabar axes, recurve bows with 3 draw states, Desert Nomad armor (turban, tunic, trousers,
  curled-toe boots) and six colour-coded Djinn Core lanterns. Worn armor textures repainted.
- Art is generated by `tools/model_gen.py` (palettes, models, armor textures, preview sheets).
- Fixed: Djinn max-health bonuses no longer cost you health every time you relog.
- Djinn definitions are synced to clients; Djinn Core tooltips show element and "already bound".
- New commands: `revoke`, `setlevel`, `info`.
- Equip requests from clients are rate-limited.
- Network protocol bumped to 2 (client and server must both run 0.2.0).
- Docs rewritten for the Soulrend target; new `docs/TESTING.md`.

## 0.1.0
- Phase 1 foundation and Phase 2a weapons with Epic Fight mappings.
